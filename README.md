# Portofolio Pribadi

Halo! Ini adalah repository untuk website portofolio pribadi saya. Website ini saya buat untuk menampilkan profil singkat, beberapa hasil tugas kuliah/latihan kodingan, dan proyek yang pernah saya kerjakan.

## 📌 Apa Saja Isi Website Ini?
- **Profil / Tentang Saya**: Perkenalan singkat mengenai diri saya.
- **Daftar Proyek & Tugas**: Menampilkan proyek yang pernah saya buat (seperti perancangan skema basis data SQL, program sederhana, dll).
- **Kontak**: Bagian informasi kontak untuk terhubung dengan saya.

## 🔗 Link Website
Website ini disimpan di Vercel dan bisa langsung dilihat di sini:  
👉 [Web Portofolio Saya](https://web-portofolio-git-main-crystal-75f1.vercel.app)

## 🛠️ Teknologi yang Digunakan
- **HTML** (`index.html`) - Untuk membuat struktur halaman web.
- **CSS** (`portofolio.css`) - Untuk mengatur tampilan, warna, dan tata letak.
- **JavaScript** (`portofolio.js`) - Untuk menambahkan fungsi interaktif pada web.
